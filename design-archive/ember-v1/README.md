# Ember v1 — archived design

A complete, runnable copy of the app as it looked before the "About You" rename and visual refresh
(saved 15 Sept 2026). Nothing in here is used by the current app.

What it contains: the original espresso / mango / vanilla design, Archivo + Inter + IBM Plex Mono,
Today view, timeline, calendar, search, media wall, Lockbin, public diaries, photo & video upload,
stickers and GIF search.

## Run it on its own

```bash
cd design-archive/ember-v1
npm install
npm run dev -- --port 5174
```

It reads the same browser storage as the current app (`ember:v1`), so on the same machine it shows
the same diary.
